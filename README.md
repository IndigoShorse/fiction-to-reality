# Fiction to Reality (F2R)

> **"You are not a viewer. You are a Colleague."**

F2R is an open research laboratory where we turn fiction into engineering specifications. We take fictional technologies and use real physics, biology, and information theory to figure out how they could actually work.

## 🔴  The Manifesto

*   **You are a participant, not a consumer.** You work in our workshop, developing specific technologies.
*   **There are no stupid questions.** A question can only be misunderstood by the one answering it.
*   **Functional minimalism.** We build only what solves the current task. Simplicity = speed.

## 🗺️  Project Structure (The Pipeline)

The project is divided into three stages. The core UI is unified (Cards with a Core text and a `[Fan / Engineer]` toggle powered by AI), but the status of the data changes:

*   **`/lab` (Laboratory):** *Status: Hypothesis / Gap.* 
    *   Fandoms: Harry Potter, Belyaev, Strugatsky. 
    *   *Goal:* Find inconsistencies in the lore.
*   **`/workshop` (Workshop):** *Status: In Development / Spec.* 
    *   Fandoms: Crossovers + Universal Translator. 
    *   *Goal:* Write technical specs using our "Dual-Translation" AI (a semantic bridge that extracts the core meaning and adapts it for different generations).
*   **`/learn` (Education):** *Status: Solved Case.* 
    *   Fandom: Jules Verne. 
    *   *Goal:* Prove that fiction has already become reality.

## 🚀  Tech & Economics

*   **Strategy:** RU-First (for now). Focused on the Russian-speaking audience.
*   **Tech Stack:** Vanilla HTML/CSS/JS (Frontend), PostgreSQL (DB), LLM Agent (AI).
*   **Auth & Payments:** Yandex ID, SBP (Russian Fast Payment System).
*   **Economics:** Club format (Patron). No ads, no sponsors.

## 🛠️  Current Status

We are building a "Wild MVP" — a static prototype to test if people are interested in reading crossovers and toggling between Lore and Spec perspectives.
